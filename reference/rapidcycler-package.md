# rapidcycler: Rapid Cycle Analysis (RCA) for a Global Network

A collection of methodologies and functions that are used to perform
Rapid Cycle Analysis (RCA), developed for the Global Vaccine Data
Network (GVDN). Functionality covers the whole process, from data
aggregation and validation, to analysis and result visualisation.
